
# 🛒 Shopping Research Agent

An AI-powered shopping research agent built using:

- Google Gemini
- LangChain
- LangGraph
- Streamlit
- Google Colab
- GitHub
- Render

## Features

- Understands shopping requirements
- Searches products
- Analyzes products
- Compares products
- Recommends suitable products

## Example

Find the best wireless headphones under ₹5000 for studying.
